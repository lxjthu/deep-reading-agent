# 论文精读提示词体系生成器
> 上传一篇种子论文后，使用以下元提示词，自动生成一套与该论文领域、理论传统和研究类型高度匹配的多维度精读提示词体系

---

## 第一步：论文解析与领域识别

```
请对我上传的这篇论文进行快速解析，完成以下识别任务，结果将用于生成定制化精读提示词体系。

请依次输出：

1. 【学科归属】
   这篇论文属于哪个一级学科与二级学科方向？
   （例：社会学—组织社会学；公共管理—地方治理；经济学—产业经济学）

2. 【研究类型】
   从以下选项中选择最匹配的类型（可多选）：
   - 单案例深描 / 多案例比较 / 大样本统计实证 / 混合方法
   - 历史演化分析 / 横截面结构分析 / 过程追踪
   - 理论建构型 / 理论检验型 / 理论修正型 / 政策评估型

3. 【核心理论传统】
   论文显性援引或隐性依托的理论框架是什么？
   （例：新制度主义、全球价值链理论、社会网络分析、IAD框架、扎根理论等）

4. 【核心解释变量与被解释变量】
   论文试图解释什么现象（Y），用什么机制或变量解释（X）？

5. 【分析层次】
   个体 / 组织 / 产业 / 社区 / 区域 / 国家 / 跨国

6. 【方法论特征】
   数据类型、田野方式或计量策略的简要描述

直接输出识别结果，不做铺垫性表述。
```

---

## 第二步：维度需求判断

```
基于第一步的识别结果，请判断这篇论文最需要从哪些分析维度展开精读。

判断逻辑如下：

A. 【必选维度】适用于所有论文类型的基础维度，包括：
   - 研究问题与学科定位
   - 理论框架与概念体系
   - 数据来源与方法论
   - 因果机制与论证链条
   - 可推广性与理论贡献
   - 整体评价与核心局限

B. 【条件维度】根据论文类型激活，判断规则如下：

   研究设计类型：
   - 若为案例研究类（单案例／多案例／过程追踪）
     → 激活：案例选择逻辑、案例呈现方式（阶段划分依据、多案例对比维度设计）
     → 不激活：结果呈现与因果识别策略
   - 若为定量实证类（回归分析／准自然实验／大样本统计）
     → 激活：结果呈现与因果识别策略（回归规格选择、稳健性检验逻辑、内生性处理）
     → 不激活：案例选择逻辑、案例呈现方式
   - 若为混合方法类
     → 同时激活上述两组维度，并增加：定性与定量结果的整合逻辑

   理论与内容类型：
   - 若涉及制度分析 → 激活：制度情境与历史脉络、规则体系分析
   - 若涉及社会关系 → 激活：社会网络结构、社会资本类型、嵌入性分析
   - 若涉及产业／市场 → 激活：市场结构、价值链治理、产业政策、技术轨道
   - 若涉及公共资源治理 → 激活：行动情境、设计原则对照、多中心治理
   - 若涉及权力与不平等 → 激活：权力关系与利益结构、分配正义
   - 若涉及跨尺度问题 → 激活：跨尺度互动与尺度错配
   - 若为政策评估类 → 激活：政策含义与实践转化、政策因果识别
   - 若为比较研究类 → 激活：案例选择逻辑、比较维度设计、文献对话

C. 【排除维度】与本论文明显不相关的维度应予排除，并说明排除理由。

请输出：
- 激活的维度清单（含激活理由）
- 排除的维度清单（含排除理由）
- 预计生成的维度总数（建议10-20个，视论文复杂度调整）

直接输出判断结果，不做铺垫性表述。
```

---

## 第三步：提示词体系生成

```
基于前两步的识别与判断结果，请为这篇论文生成一套完整的定制化精读提示词体系。

生成规范如下：

【结构规范】
- 以"前导：分析框架定位"开篇，包含3个定位问题，帮助读者在展开各维度分析前锁定论文的核心坐标
- 各维度按数字序号连续排列，不分模块，不分组
- 每个维度包含：维度名称、描述（一句话说明该维度的分析焦点）、默认问题、提示词正文
- 末尾附"使用说明"，包含推荐阅读顺序与按子问题类型的维度选用建议

【提示词正文规范】
每条提示词须满足：
1. 语言风格：以资深学者口吻直接发问，不使用"请问""能否"等客气表达
2. 问题颗粒度：每条提示词包含3-4个子问题，从"识别事实"到"评估逻辑"到"批判性判断"递进
3. 锚定原文：每个子问题须要求引用原文具体段落、数据或方法论细节，不接受泛泛概括
4. 批判导向：至少有一个子问题指向论文的潜在缺陷、逻辑漏洞或被忽视的替代解释
5. 结尾统一：每条提示词以"直接输出分析，不做铺垫性表述"结尾

【内容定制规范】
- 维度名称与描述须使用该论文所属学科的专业术语，不使用通用化表达
- 子问题中的概念举例须与论文的理论传统匹配
  （例：社会学论文用"场域""惯习"；产业论文用"技术轨道""价值链治理"；治理论文用"行动情境""设计原则"）
- 批判性子问题须针对该类研究的典型缺陷，尤其注意研究设计类型的差异：
  · 案例研究的典型缺陷：选择性偏差、过程描述替代机制分析、单一信息来源
  · 定量实证的典型缺陷：内生性处理不足、稳健性检验流于形式、变量操作化与理论概念脱节
  · 混合方法的典型缺陷：定性与定量结果相互独立而非真正整合

【质量控制】
生成完成后，请自我检查：
- 是否有维度存在实质性重叠？若有，合并处理
- 是否有对该论文明显不适用的维度混入？若有，删除
- 维度总数是否在合理范围内（10-20个）？
- 整套提示词是否形成了从"问题定位"到"整体评价"的完整分析闭环？

直接输出完整提示词体系，不做铺垫性表述。
```

## 第四步：提示词体系校准（可选）

```
请基于以下反馈对刚刚生成的提示词体系进行校准：

【可选校准指令，按需选用】

A. 深度校准
   "请将维度[X]的批判性力度加强，当前子问题过于温和，需要更直接地指向该维度的核心方法论缺陷"

B. 合并校准
   "维度[X]与维度[Y]存在实质性重叠，请合并为一个维度，保留两者最有价值的子问题"

C. 拆分校准
   "维度[X]涵盖内容过多，请拆分为两个独立维度，分别聚焦[子主题A]与[子主题B]"

D. 替换校准
   "维度[X]与本论文关联度不足，请替换为专注于[具体分析焦点]的新维度"

E. 增补校准
   "当前体系缺少对[具体分析焦点]的覆盖，请增补一个专门维度"

F. 术语校准
   "请将整套提示词中的术语体系统一调整为[指定理论传统]的话语风格"

G. 风格校准
   "请将整套提示词的分析立场调整为更偏向[批判性/建设性/描述性]"

直接输出校准后的修订内容，不做铺垫性表述。
```

## 使用流程说明

**标准流程（首次使用）**

```
步骤 1  上传种子论文（PDF或全文粘贴）
步骤 2  运行第一步提示词 → 获得论文解析结果
步骤 3  运行第二步提示词 → 获得维度激活清单
步骤 4  运行第三步提示词 → 获得完整提示词体系
步骤 5  按需运行第四步 → 对体系进行精细校准
```

**快速流程（熟悉后使用）**

```
将第一步至第三步合并为单次调用：

"请对我上传的这篇论文完成以下三项任务并一次性输出：
（1）学科归属、研究类型、理论传统、核心变量、分析层次、方法论特征的快速识别
（2）基于识别结果判断应激活与排除的分析维度
（3）生成完整的定制化精读提示词体系，遵循标准生成规范"
```

**迭代精读流程**

```
生成提示词体系后，将论文与各维度提示词逐一配对提交，
建议顺序：前导定位 → 核心理论维度 → 方法论维度 → 批判性维度 → 整体评价维度
每次提交一个维度，获得聚焦分析后再推进下一个维度
```
