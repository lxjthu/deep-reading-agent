# 12维度案例研究论文精读解析提示词体系

以下是以**资深社会学家与公共管理学家**视角构建的完整提示词套件，适用于案例研究类学术论文的系统性精读。

---

## 维度 1：研究问题与创新定位

**描述：** 论文解决了什么问题？创新点在哪里？

**默认问题：** 这篇论文的核心研究问题是什么？

```
请分析这篇论文的核心研究问题与创新贡献。

要求：
1. 聚焦核心贡献，避免泛泛而谈
2. 最多识别3点，避免过度扩展
3. 引用论文的具体段落、数据、方法论细节
4. 直接输出分析内容，不要"好的""作为..."等客套开场白
```

---

## 维度 2：理论框架与概念体系

**描述：** 论文依托哪些理论？概念是否自洽？

**默认问题：** 论文采用了哪种理论框架，其适配性如何？

```
请解析本文的理论框架与核心概念体系。

要求：
1. 明确指出论文援引的主体理论（如新制度主义、街头官僚理论等），并引用原文定义
2. 判断理论框架与研究问题之间的逻辑适配性——是否存在"理论借用"却缺乏本土化修正的问题
3. 识别关键概念的操作化方式，指出是否存在概念模糊或内涵漂移
4. 直接输出分析，不做铺垫性表述
```

---

## 维度 3：案例选择逻辑

**描述：** 为何选择这个案例？选案标准是否严谨？

**默认问题：** 案例的选择依据是什么，是否具有代表性或典型性？

```
请评估本文的案例选择策略及其合理性。

要求：
1. 指出作者采用的是何种案例选择逻辑（典型案例、极端案例、最大相似/最大差异等），并引用原文依据
2. 判断案例选择是否存在"确认偏误"——即倾向于选择支持预设结论的案例
3. 分析案例的时间跨度、地域范围与研究问题之间的匹配程度
4. 直接输出分析，不做铺垫性表述
```

---

## 维度 4：数据来源与研究方法

**描述：** 数据从哪来？方法是否匹配问题？

**默认问题：** 论文的数据收集与分析方法是否严谨？

```
请审查本文的数据来源、收集方式与分析方法。

要求：
1. 列举论文使用的全部数据类型（访谈、档案、问卷、观察等），并注明规模与来源
2. 识别数据收集中的潜在偏差——如访谈对象的选择性、档案的可及性限制
3. 评估分析方法（如扎根理论、过程追踪、比较分析）与研究问题的匹配度，引用具体操作步骤
4. 直接输出分析，不做铺垫性表述
```

---

## 维度 5：案例呈现方式

**描述：** 论文如何在结构与叙事层面组织和展示案例材料？

**默认问题：** 论文对案例的呈现手法是否清晰、有效，结构逻辑是否服务于核心论点？

```
请分析本文对案例的呈现手法与叙事结构。

要求：
1. 识别论文采用的案例呈现策略——单案例研究中是否进行了阶段划分（如政策周期、事件序列），划分依据是时间、机制转折还是行动者更替；多案例研究中对比维度的选择是否系统、对称
2. 评估案例叙事的详略取舍是否服务于理论论点，还是存在"故事堆砌"而论证不足的问题
3. 指出案例呈现中的结构性缺陷——如关键节点缺失、对比案例信息不对等、过度依赖单一信息来源的叙事
4. 直接输出分析，不做铺垫性表述
```

---

## 维度 6：因果机制与论证链条

**描述：** 论文的核心论证逻辑是否成立？

**默认问题：** 论文如何建立从证据到结论的因果链条？

```
请剖析本文的核心论证结构与因果机制。

要求：
1. 还原论文的主要因果链条（X→Y的路径），引用关键论证段落
2. 识别论证中的薄弱环节——是否存在跳跃性推论、遗漏中间变量或混淆相关与因果
3. 评估作者是否对竞争性解释（rival explanations）进行了有效排除
4. 直接输出分析，不做铺垫性表述
```

---

## 维度 7：权力关系与利益结构

**描述：** 论文是否揭示了行动者背后的权力逻辑？

**默认问题：** 案例中涉及哪些关键行动者，其权力关系与利益博弈如何？

```
请分析本文对权力关系与利益结构的呈现与解释。

要求：
1. 梳理案例中的核心行动者（国家、市场、社会、个体），并引用原文对其角色的界定
2. 评估论文是否揭示了表层行为背后的结构性权力逻辑，还是停留于现象描述
3. 指出论文是否存在对弱势群体或边缘声音的系统性忽视
4. 直接输出分析，不做铺垫性表述
```

---

## 维度 8：制度情境与历史脉络

**描述：** 论文是否将案例嵌入足够的制度与历史背景中？

**默认问题：** 论文如何处理制度环境与历史条件对案例的塑造作用？

```
请评估本文对制度情境与历史脉络的处理深度。

要求：
1. 指出论文交代的制度背景（正式规则、非正式规范、历史遗产）的详尽程度，引用具体段落
2. 判断论文是否存在"去历史化"倾向——将特定历史条件下的现象普遍化
3. 分析制度情境变量在论文解释框架中的地位：是核心解释变量、控制变量还是被忽视的背景噪音
4. 直接输出分析，不做铺垫性表述
```

---

## 维度 9：可推广性与外部效度

**描述：** 论文的结论能推广到多大范围？

**默认问题：** 论文的发现具有怎样的可推广性，边界条件是什么？

```
请评估本文研究发现的外部效度与推广边界。

要求：
1. 指出作者对推广性的自我声明（原文引用），并评估其是否过度或保守
2. 识别制约推广性的关键边界条件（如特定政治体制、发展阶段、文化背景）
3. 判断论文是否具备"分析性推广"（analytic generalization）的潜力，即对理论命题的贡献
4. 直接输出分析，不做铺垫性表述
```

---

## 维度 10：政策含义与实践转化

**描述：** 论文对现实政策与治理实践有何启示？

**默认问题：** 论文的研究发现能为哪些政策议题提供依据或反思？

```
请分析本文的政策含义与实践转化价值。

要求：
1. 提炼论文明确或隐含的政策建议，引用原文表述
2. 评估政策建议与研究证据之间的逻辑距离——是否存在从学术发现到政策主张的跳跃
3. 指出论文是否忽视了政策执行的现实约束（如资源限制、官僚阻力、政治可行性）
4. 直接输出分析，不做铺垫性表述
```

---

## 维度 11：文献对话与学术定位

**描述：** 论文在学术谱系中处于什么位置？

**默认问题：** 论文与既有文献的对话是否充分，学术贡献如何定位？

```
请评估本文与既有学术文献的对话质量及其学术定位。

要求：
1. 识别论文明确回应的核心文献流派或争论，引用其援引的关键文献
2. 判断论文是对既有理论的"证实、修正、挑战还是综合"，并给出具体依据
3. 指出文献综述中的明显遗漏——哪些重要相关研究被忽视，可能影响论文的创新性声明
4. 直接输出分析，不做铺垫性表述
```

---

## 维度 12：整体评价与核心局限

**描述：** 综合判断论文的学术价值与主要不足。

**默认问题：** 这篇论文最重要的贡献与最值得商榷的局限分别是什么？

```
请对本文作出整体性学术评价，聚焦核心贡献与根本局限。

要求：
1. 用不超过3句话概括论文最实质性的学术贡献，须有具体证据支撑，避免套话
2. 指出1-2个根本性局限（非技术性细节），说明其如何影响论文结论的可靠性
3. 给出一个"如果重做这项研究"的关键改进建议，体现方法论或理论层面的深度思考
4. 直接输出分析，不做铺垫性表述
```

---

> **使用说明：** 将目标论文全文（或关键章节）附于各维度提示词之后，逐一提交即可获得系统性精读报告。建议按维度 1 → 5 → 11 → 12 的顺序优先解读，快速把握论文骨架后再深入细节维度。
