# 社会学视角12维度案例分析提示词体系
> 聚焦社会网络、社会资本与嵌入性，以资深社会学家视角对案例研究类论文展开系统性精读

---

## 维度 1：社会学问题意识

**描述：** 论文是否真正提出了社会学意义上的问题，而非停留于政策描述或管理优化？

**默认问题：** 这篇论文的核心社会学问题是什么？

```
请识别本文的社会学问题意识，判断其是否具有社会学学科的实质性关怀。

要求：
1. 指出论文试图解释的社会现象，判断其问题意识是否落在"社会结构—行动者"的张力之上，还是仅停留于政策效果或管理绩效的描述层面
2. 识别论文是否明确回应了社会学的经典议题（如秩序何以可能、不平等如何再生产、集体行动如何达成），引用原文关键表述
3. 判断研究问题是否具有"社会学的想象力"——能否将个体处境与宏观结构相连接
4. 直接输出分析，不做铺垫性表述
```

---

## 维度 2：网络结构识别

**描述：** 论文呈现的社会网络形态是什么？结构特征如何影响行动与结果？

**默认问题：** 案例中的社会网络具有怎样的结构特征？

```
请分析本文所呈现或隐含的社会网络结构及其解释效力。

要求：
1. 识别案例中的核心网络形态——是强连带主导的密集网络、弱连带主导的桥接网络，还是以结构洞（structural hole）为特征的中介网络；引用原文中描述行动者关系的具体段落
2. 评估论文是否分析了网络的关键结构属性：密度、中心性、边界跨越者（boundary spanner）、网络闭合程度，并判断这些属性如何制约或赋能行动者
3. 指出论文是否忽视了网络的动态演化——网络结构在案例时间跨度内是否发生了重组，触发机制是什么
4. 直接输出分析，不做铺垫性表述
```

---

## 维度 3：社会资本的类型与分布

**描述：** 案例中的社会资本属于哪种类型？其分布是否不均等？

**默认问题：** 论文如何处理社会资本的类型区分与不平等分布问题？

```
请辨析本文涉及的社会资本类型及其分布逻辑。

要求：
1. 区分论文中出现的社会资本形态：黏合型（bonding）社会资本强化内部团结，桥接型（bridging）社会资本连接异质群体，连接型（linking）社会资本跨越垂直权力层级——论文侧重哪种，引用原文依据
2. 评估论文是否呈现了社会资本的不平等分布——哪些行动者占有更多网络资源，这种占有如何与阶级、性别、族群等结构性位置相关联
3. 判断论文是否区分了社会资本的"存量"（已有关系资源）与"动员能力"（将关系转化为实际支持的能力），两者的分析是否混淆
4. 直接输出分析，不做铺垫性表述
```

---

## 维度 4：嵌入性的层次分析

**描述：** 行动者的行为在多大程度上被社会关系与制度结构所嵌入？

**默认问题：** 论文如何理解和分析行动者的嵌入性？

```
请评估本文对嵌入性（embeddedness）的理论把握与经验分析深度。

要求：
1. 识别论文涉及的嵌入性层次：关系性嵌入（dyadic ties的质量与历史）、结构性嵌入（行动者在整体网络中的位置）、制度性嵌入（正式规则与非正式规范的约束）、认知性嵌入（共享的意义框架与文化图式）——论文覆盖了哪些层次，引用原文
2. 判断论文是否陷入"过度社会化"陷阱——将行动者完全化约为关系结构的产物，抹除了其能动性与策略空间
3. 评估嵌入性分析是否具有历史纵深：行动者当前的嵌入状态是如何在特定历史过程中形成的
4. 直接输出分析，不做铺垫性表述
```

---

## 维度 5：案例呈现方式

**描述：** 论文如何在结构与叙事层面组织和展示社会关系材料？

**默认问题：** 论文对案例的呈现手法是否有效揭示了社会网络与嵌入性的动态过程？

```
请分析本文对案例的呈现手法与社会学叙事结构。

要求：
1. 识别论文采用的案例呈现策略：单案例研究中是否以关系事件或网络重组节点作为阶段划分依据，而非仅依赖时间顺序或政策节点；多案例研究中对比维度是否覆盖了网络结构差异、资本类型差异、嵌入情境差异
2. 评估案例叙事是否有效呈现了关系过程（relational process）——行动者之间的互动序列、信任积累或断裂、资源流动路径是否得到充分描绘，还是被静态的结构快照所替代
3. 指出案例呈现中的社会学盲点：是否存在将集体行动归因于个体魅力而遮蔽网络机制、以组织边界替代关系边界划定分析单元等结构性叙事缺陷
4. 直接输出分析，不做铺垫性表述
```

## 维度 6：信任机制与关系质量

**描述：** 论文是否深入分析了信任的生产机制及其对网络运作的影响？

**默认问题：** 案例中的信任是如何建立、维持或崩解的？

```
请分析本文对信任机制与关系质量的处理深度。

要求：
1. 区分案例中信任的类型基础：基于计算的工具性信任、基于重复互动的经验性信任、基于共同身份认同的情感性信任——论文呈现了哪种机制，引用具体情节或段落
2. 评估论文是否分析了信任的脆弱性与修复机制——信任断裂的触发条件、背叛的社会代价、关系修复的路径
3. 判断论文是否将信任简化为一个静态的前提条件，而非将其作为需要持续社会生产的动态过程加以解释
4. 直接输出分析，不做铺垫性表述
```

## 维度 7：边界工作与群体认同

**描述：** 行动者如何划定"我们"与"他们"的边界，这种边界如何塑造网络结构？

**默认问题：** 案例中的社会边界是如何被建构、维持和挑战的？

```
请分析本文对社会边界建构与群体认同机制的呈现。

要求：
1. 识别案例中的边界划定实践——行动者通过哪些符号、话语、仪式或制度手段区分内外群体，引用原文中的具体边界标记
2. 评估论文是否分析了边界的双重效应：对内强化黏合型社会资本与集体行动能力，对外产生排斥、歧视或资源封锁
3. 判断论文是否呈现了边界的竞争性与流动性——不同行动者对边界的争夺，以及边界在特定条件下的松动或重组
4. 直接输出分析，不做铺垫性表述
```

## 维度 8：制度嵌入与场域逻辑

**描述：** 社会网络与社会资本运作于怎样的制度场域之中？场域规则如何塑造关系实践？

**默认问题：** 论文如何处理社会网络与制度结构之间的相互嵌入关系？

```
请评估本文对制度嵌入与场域逻辑的分析深度。

要求：
1. 识别案例所处的社会场域（布尔迪厄意义上的），分析该场域的惯习（habitus）、资本构成与游戏规则如何规定了哪些关系实践是可能的、合法的或有效的
2. 评估论文是否分析了正式制度与非正式网络之间的张力：网络关系是在正式制度框架内运作、绕过正式制度，还是与正式制度形成共生性嵌套
3. 判断论文是否呈现了场域变迁对网络结构的冲击——政策改革、市场化、技术变革等外部冲击如何重塑既有的嵌入性关系格局
4. 直接输出分析，不做铺垫性表述
```

---

## 维度 9：权力不对称与网络排斥

**描述：** 网络结构内部是否存在权力不对称？谁被系统性地排斥在网络之外？

**默认问题：** 论文是否揭示了社会网络中的权力差异与排斥机制？

```
请分析本文对网络内部权力不对称与排斥机制的揭示程度。

要求：
1. 识别网络中的权力差异：谁占据结构洞位置从而获得信息与资源的中介优势？谁处于网络边缘或被隔离于关键子网络之外？引用原文中反映权力位置的具体描述
2. 评估论文是否分析了网络排斥的再生产机制——弱势行动者如何因缺乏初始社会资本而被持续排斥于资源网络之外，形成"马太效应"
3. 判断论文是否对"社会资本"持批判性立场——社会资本对占有者有利，是否同时对未占有者构成结构性障碍，论文是否对此保持了足够的分析张力
4. 直接输出分析，不做铺垫性表述
```

## 维度 10：网络动员与集体行动

**描述：** 社会网络如何被动员以实现集体目标？动员的条件与限制是什么？

**默认问题：** 案例中的集体行动是如何通过网络机制得以组织或受阻的？

```
请分析本文对网络动员机制与集体行动逻辑的解释。

要求：
1. 还原案例中集体行动的网络动员路径：关键节点行动者如何激活休眠关系、跨越网络边界、整合异质资源——引用具体动员事件或过程描述
2. 评估论文是否分析了动员失败或集体行动困境的网络根源：搭便车问题、关系断裂、结构洞被封锁、核心节点退出等
3. 判断论文是否区分了"网络的存在"与"网络的激活"——潜在关系网络转化为实际动员能力需要哪些触发条件，论文是否对此有清晰解释
4. 直接输出分析，不做铺垫性表述
```

## 维度 11：可推广性与中层理论贡献

**描述：** 论文的网络与嵌入性发现能否上升为可迁移的中层理论命题？

**默认问题：** 论文对社会网络与社会资本理论的贡献体现在哪里，边界条件是什么？

```
请评估本文在社会网络与社会资本理论层面的学术贡献及其推广边界。

要求：
1. 识别论文是否提炼出了可迁移的中层理论命题（如"在X类制度情境下，Y类网络结构将产生Z类集体行动结果"），引用论文结论部分的核心表述
2. 评估该命题的推广边界：哪些结构性条件（政治体制、市场化程度、文化传统、城乡差异）是其成立的前提，论文是否对此有清醒的自我限定
3. 判断论文对格兰诺维特、科尔曼、伯特、布尔迪厄等社会网络与社会资本核心理论的回应是"证实、修正、挑战还是综合"，并给出具体依据
4. 直接输出分析，不做铺垫性表述
```

## 维度 12：整体评价与社会学深度判断

**描述：** 综合判断论文的社会学理论深度与经验分析质量。

**默认问题：** 这篇论文在社会网络与嵌入性研究传统中处于什么位置，其核心局限是什么？

```
请对本文作出整体性社会学评价，聚焦其理论深度与根本局限。

要求：
1. 用不超过3句话概括论文在社会网络、社会资本或嵌入性研究上最实质性的学术贡献，须有具体证据，避免"填补空白""有重要意义"等套话
2. 指出1-2个根本性社会学局限——例如：将网络视为工具性资源而忽视其文化意义维度；以关系结构解释一切而遮蔽了物质利益与意识形态的独立作用；对权力与不平等的分析流于表面
3. 给出一个"如果重做这项研究"的核心改进方向，须落在社会学理论或方法论层面（如引入社会网络分析的形式化方法、增加纵向追踪设计以捕捉网络动态、引入布尔迪厄场域理论深化嵌入性分析）
4. 直接输出分析，不做铺垫性表述
```

> **使用说明：** 本套提示词专为社会网络、社会资本与嵌入性视角的案例研究精读设计。建议优先阅读维度 1（问题意识）→ 维度 2（网络结构）→ 维度 4（嵌入性）→ 维度 12（整体评价），快速定位论文的社会学立场，再按需深入其余维度。与公共管理版提示词配合使用时，重点关注维度 8（制度嵌入）与维度 9（权力排斥）的交叉分析。
