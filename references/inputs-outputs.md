# 输入输出与恢复

workspace.json 声明本地 schema_version=1，library/index.json 保存稳定文献ID、元数据、标签和来源。sources/ 按 SHA-256 保存原文件、提取JSON与Markdown。

只有首页题名和文件名共同支持的唯一候选才自动关联；参考文献中的题名不能作为本文身份。.source.md 是来源说明。

证据包含文件哈希、PDF物理页序、原文字符区间。PDF公式、表格、双栏顺序和图像仍需查看原页。--exclusions 接收 [{page,start,end,reason}]，用于审核后排除其他文章片段；原始页及被排除内容仍保留。多文章摘要汇总页先审核，不能简单整页删除。

runs/<id>/ 保存计划、实际提示词版本和哈希、各步完整messages、响应及可用用量。运行数据包含用户原文。缺模板、变量错误、输入超限、输出截断和运行中提示词变更均不标记步骤成功。

artifacts/<entry-id>/ 使用唯一文件名及元数据sidecar。origin 区分 ai/user；人工编辑创建新版本。AI结果为候选稿。

恢复只复用已完成且输入一致的步骤。取消在步骤边界生效。异常遗留 .write.lock 时，先核对进程，再处理锁；不要同时以同一run_id执行两个任务。

本地备份按文件哈希校验并导入空目录。网站 .dra 保留原表和附件，另建映射表与本地文献投影；不属于生产数据库恢复工具。
