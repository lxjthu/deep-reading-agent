# 逐篇提取变量选择与研究方法

用于用户要求“每篇论文采用了哪些变量/方法、如何计算、如何操作或复现”的专题核读。默认采用已认可的企业 TFP 回答结构；随论文实际内容调整，不要求无证据地补齐栏目。

## 交付结构

1. 先给逐篇对照：完整题名或可识别作者/题名、基准方法、替代/稳健性方法、变量披露程度、证据。
2. 各篇独立记录变量角色（因变量、核心自变量、生产投入、控制、中介、调节、工具变量）、名称/符号、经济含义、原始字段、来源、时间/单位、公式及预处理。严格区分用于测算指标的变量和随后解释指标的回归变量。
3. 从数据到结果写操作步骤：样本与面板键、原始数据获取与匹配、字段合成、价格/单位调整、变换、估计设定、结果提取和验收。注明软件、接口、必要输入与输出。
4. 有公式时保留原始符号并解释各项。没有充分信息时写“未披露/需补查”，不能用其他论文定义、常识或软件默认值冒充作者做法。
5. 用户需要代码时提供可保存的代码文件与页面代码块，明确是作者原程序、改编或本次补写。查软件作者文档/源码核对接口；报告实际运行范围。缺数据、依赖或授权时不声称代码已通过估计测试。仅列方法名称的论文不能被改写成已完成的复现方案。
6. 区分实际采用、稳健性采用、引用介绍与代理推导。价格指数、行业分组、投入时序、初始存量等代理补充选择单列。跨论文归纳保留这些差异。

## 原文证据与前端

- PDF 按物理页定位，印刷页码另记；OCR Markdown 按文件与行号定位，未知页码不补猜。保留来源哈希、材料范围及核读/完整精读状态。
- 证据点击默认在独立窗口或标签页打开，保留回答页；使用 target="_blank"、rel="noopener noreferrer"，定位到原段落/页。PDF 优先展示原页图像并提供 PDF 原件对应页入口，不能仅以提取文字代替公式表格核验。
- 在独立 Skill 阅读目录展示：目录、逐篇方法表、变量表、操作步骤、公式、代码下载、来源与缺项。需要添加专题页面时保留既有页面与入口；生成器也应保留该行为。可信来源链接应在安全渲染后按明确的本地文件/锚点映射接回，不能放宽任意用户 Markdown 的链接安全规则。
- 按交付面检查：公式显示、表格、证据链接新窗口与定位、代码下载、窄屏可读性。只有真实问题才修复，不为低影响指令更新增加机械测试。

## 将文献方法与用户数据对接

先检查文件字典、变量标签、原始构造程序和少量记录，再对关键字段做覆盖、缺失、唯一性与有效值检查。优先原始未缩尾字段，避免对已缩尾控制比率反推金额。交付“方法所需字段—现有字段/文件—覆盖与问题—需补数据/需决策口径”清单。

明确区分：字段已存在但某些记录缺失；字段完全缺失；需要额外价格/行业等外部数据；仅需要口径选择。若没有实际估计，不能把字段齐备写成可无条件复现。读取用户数据只为当前研究任务，不将用户面板、原文或本机路径放入通用技能包。
