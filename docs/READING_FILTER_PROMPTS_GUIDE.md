# 精读与筛选提示词说明

本文档解释精读（七步/四步/长文本）、文献筛选、对比总结共 28 个提示词的设计逻辑、各自用途和可修改方向。

---

## 一、七步精读（定量）— 7 个提示词

### 设计逻辑

七步精读按定量实证论文的分析流程拆分为 7 个步骤，每步由独立提示词驱动。LLM 角色统一设定为"Daron Acemoglu 级别的顶级计量经济学家"，确保输出具有专业深度。

```
Step 1 研究概览 → Step 2 理论与假说 → Step 3 数据考古
     → Step 4 变量与度量 → Step 5 识别策略 → Step 6 结果解读
     → Step 7 批判与展望
```

---

### Step 1：研究概览（`step_1_overview`）

**触发场景**：七步精读第一步

**当前内容要点**：
- 用一句话概括研究主题和核心结论
- 分析问题意识（解决什么科学问题）
- 评估重要性（"So What?"问题）
- 定位贡献（理论 + 实践）

**可修改方向**：
- 增加对期刊等级的判断要求
- 要求输出论文的边际贡献（相对于最相近的 1-2 篇文献）
- 改变角色人设（如改为领域专家而非通用计量经济学家）

---

### Step 2：理论与假说（`step_2_theory`）

**触发场景**：七步精读第二步

**当前内容要点**：
- 文献谱系：起点文献、理论框架来源、分析视角依据、机制参考、方法借鉴
- 理论基础：核心理论在本研究中的应用
- 待检验假说：H1、H2 等
- 创新点：与前人对比的新意
- 逻辑推演：假说背后的微观机制

**可修改方向**：
- 要求绘制理论框架图（Mermaid 语法）
- 增加对"理论选择合理性"的批判性评估
- 要求对比竞争性理论框架

---

### Step 3：数据考古（`step_3_data`）

**触发场景**：七步精读第三步

**当前内容要点**：
- 数据来源类型（公开/独家/调研/文本分析）
- 获取与清洗细节
- 数据生成过程（DGP）中的系统性偏差

**可修改方向**：
- 增加对样本量充分性的统计功效评估
- 要求检查数据可得性（是否公开可复现）
- 增加对时间跨度与频率的评估

---

### Step 4：变量与度量（`step_4_vars`）

**触发场景**：七步精读第四步

**当前内容要点**：
- 核心变量定义（Y 和 X）
- 衡量方式（直接观测 / 代理变量 / 构建指标）
- 控制变量选择依据
- 机制分析变量与特殊处理（对数化、去通胀等）

**可修改方向**：
- 增加对变量度量有效性的量化评估
- 要求区分核心变量与控制变量的理论依据强度
- 增加对"测量误差对估计方向的影响"分析

---

### Step 5：识别策略（`step_5_identification`）

**触发场景**：七步精读第五步

**当前内容要点**：
- 核心回归方程
- 内生性来源识别（遗漏变量/反向因果/测量误差）
- 解决策略（IV/DID/RDD/Bunching）
- 机制检验（Mermaid 影响机制图谱）
- 稳健性检验清单

**可修改方向**：
- 增加对 IV 相关性和排他性约束的具体检验要求
- 要求评估外生冲击的可信度
- 增加"局部平均处理效应（LATE）"解读

---

### Step 6：结果解读（`step_6_results`）

**触发场景**：七步精读第六步

**当前内容要点**：
- 显著/不显著系数解读
- 经济学含义分析
- 与理论一致性和其他文献对比
- 政策含义

**可修改方向**：
- 要求报告效应量大小和实际意义（不只是统计显著性）
- 增加对 R²、拟合优度的评估
- 要求区分统计显著和经济学显著

---

### Step 7：批判与展望（`step_7_critique`）

**触发场景**：七步精读第七步

**当前内容要点**：
- 致命伤（Achilles' Heel）：最大弱点
- 未来选题：1-2 个可执行的新研究方向

**可修改方向**：
- 增加对论文"可复现性"的评估
- 要求给出改进建议的具体实施方案
- 增加对研究伦理的审查

---

## 二、四步精读（定性）— 4 个提示词

### 设计逻辑

四步精读按定性研究分析流程拆分为 4 层（Layer），每层有独立提示词。角色人设统一为"社会科学研究学者/专家"。与七步精读不同，四步精读的提示词更长、结构化要求更细，因为定性论文的分析维度更灵活。

```
L1 背景与语境 → L2 理论框架 → L3 论证逻辑 → L4 价值与启示
```

---

### L1：背景与语境（`L1_Context_Prompt`）

**触发场景**：四步精读第一步

**当前内容要点**：
- 论文体裁分类（Case Study / QCA / Review / Quantitative / Theoretical）
- 核心问题（理论缺漏、实践矛盾、子问题分解、创新点）
- 政策文件提取（名称、年份、层级、核心内容）
- 现状数据提取（数据项、数值、单位、背景）
- 研究重要性（理论 + 实践双维度）
- 关键文献（作者、年份、核心观点）

**可修改方向**：
- 调整体裁分类体系（如增加"混合方法"类型）
- 增加对"研究问题边界"的分析
- 要求输出研究时间线（该领域研究演进脉络）

---

### L2：理论框架（`L2_Theory_Prompt`）

**触发场景**：四步精读第二步

**当前内容要点**：
- 经典理论回顾（名称、作者、时间、源流、摘要、应用）
- 核心构念（名称、定义、操作化）
- 构念关系（起始→目标、作用机制、路径）
- 理论框架（整体结构、创新方式）
- 理论贡献（拓展/修正/新概念/新命题）

**动态占位符**：无（全文固定模板）

**可修改方向**：
- 要求绘制理论框架图（Mermaid 语法）
- 增加对"构念操作化合理性"的评估
- 要求对比竞争性理论框架

---

### L3：论证逻辑（`L3_Logic_Prompt`）

**触发场景**：四步精读第三步

**动态占位符**：`{genre}` — 论文研究体裁（在 L1 中自动识别）

**当前内容要点**：
- 根据 `{genre}` 自动适配输出格式：
  - Case Study → 过程模型（阶段、事件、策略）
  - QCA → 因果路径/条件组合
  - Quantitative → 假设检验结果
  - Review → 整合框架/演进图谱
  - Theoretical → 概念推导/模型构建
- 统一分析：核心问题、机制组成、作用过程、证据支撑

**可修改方向**：
- 调整各体裁的分析深度
- 增加新的体裁类型（如"实验研究"）
- 要求输出统一的 Mermaid 流程图

---

### L4：价值与启示（`L4_Value_Prompt`）

**触发场景**：四步精读第四步

**当前内容要点**：
- 研究缺口（理论/方法/实践/数据四个层面）
- 学术贡献（理论/方法/实证/综合）
- 实践启示（政策/实践/研究/技术四个维度）
- 价值定位（学术价值、实践价值、创新性、可推广性）
- 未来展望（可选）

**可修改方向**：
- 增加"与同类研究的对比评价"
- 要求给出"后续研究优先级排序"
- 增加对研究伦理和社会影响的评估

---

## 三、长文本精读 — 13 个提示词

### 设计逻辑

长文本精读是一次性分析整篇论文，按维度拆分为 12 个固定维度 + 1 个自定义维度。每个维度的提示词简短精炼（6-8 行），聚焦于"分析什么"而非"如何输出"，给 LLM 更多发挥空间。

与七步/四步的区别：
- **七步/四步**：提示词很长，包含详细的角色人设、格式要求、分析框架
- **长文本**：提示词很短，只指定分析焦点和几条要求

```
overview / theory / methodology / data_source / variable_measurement
/ identification_assumptions / results / mechanism / robustness
/ external_validity / contributions_limitations / writing_quality / custom
```

---

### 各维度一览

| 维度 | 槽位 key | 分析焦点 |
|------|---------|---------|
| 研究问题 | `overview` | 核心贡献，最多 3 点，引用具体段落 |
| 理论框架 | `theory` | 理论来源、适用性、缺口 |
| 识别策略 | `methodology` | 方法论解读（先通俗后批判），因果推断可靠性 |
| 数据来源 | `data_source` | 数据渠道、样本代表性、偏差 |
| 变量度量 | `variable_measurement` | 变量定义、度量可靠性、代理变量问题 |
| 识别假设 | `identification_assumptions` | 关键因果假设、可信度、不成立时的稳健性 |
| 统计结果 | `results` | 聚焦数据，统计显著性与实际意义 |
| 机制分析 | `mechanism` | 作用机制是否明确、证据充分性、竞争性解释 |
| 稳健性检验 | `robustness` | 检验覆盖度、结果敏感性 |
| 外部有效性 | `external_validity` | 推广边界、场景/群体/时期限制 |
| 贡献与局限 | `contributions_limitations` | 核心贡献（≤3 点）、作者自述 vs 额外发现 |
| 写作质量 | `writing_quality` | 结构、逻辑、图表、引用规范 |
| 自定义问题 | `custom` | 用户自由提问，引用论文具体段落支撑 |

### 可修改方向

- **通用调整**：在所有维度提示词中加入"使用 Markdown 格式输出"或"要求输出字数 500-800 字"
- **学科适配**：修改各维度的分析焦点以适配特定学科（如医学论文可增加"临床试验设计"维度）
- **深度调整**：增加具体要求如"列出所有表格和图表的关键发现"
- **custom 维度**：这个维度在用户自由提问时使用，通常不需要修改

## 四、文献筛选 — 3 个提示词

### 设计逻辑

文献筛选有三种"人格"（persona），每种关注不同的筛选标准。三种模式共享同一个 JSON 输出格式，但评分权重和输出字段不同。

```
探索者（Explorer）  → 适合入门，找经典/开创性文献
评审者（Reviewer）  → 适合写综述，找理论贡献和方法多样性
实证主义者（Empiricist） → 适合深读，找因果识别严谨的实证论文
```

**动态占位符**（三个提示词通用）：`{topic}`、`{title}`、`{journal}`、`{year}`、`{authors}`、`{abstract}`

---

### 探索者模式（`explorer`）

**触发场景**：筛选模式下选择"探索者"

**筛选侧重**：
- 期刊等级（最高权重）
- 开创性（是否提出基础理论/新范式）
- 相关性

**特色输出**：`is_seminal`（是否为经典文献）、`journal_tier`

**可修改方向**：
- 增加更多中文核心期刊
- 调整期刊等级列表（如增加学科特定顶刊）
- 修改评分权重（如降低期刊等级权重，提高相关性权重）

---

### 评审者模式（`reviewer`）

**触发场景**：筛选模式下选择"评审者"

**筛选侧重**：
- 理论贡献（是否提出新理论框架/分类）
- 方法多样性（是否代表不同方法论）
- 期刊质量
- 是否为元分析/系统综述

**特色输出**：`theoretical_lens`（理论视角）、`method`（研究方法）

**可修改方向**：
- 增加"跨学科价值"评估维度
- 要求识别论文所属的学术流派

---

### 实证主义者模式（`empiricist`）

**触发场景**：筛选模式下选择"实证主义者"

**筛选侧重**：
- 实证严谨性（最高权重）— 是否使用 DID/RDD/IV/RCT
- 变量清晰度
- 期刊质量
- 对纯理论/定性论文降权

**特色输出**：`is_empirical`（是否实证）、`identification_strategy`（识别策略）、`key_variables`（关键变量）

**可修改方向**：
- 增加对"数据可得性/可复现性"的评估
- 增加对样本量和统计功效的要求
- 修改识别策略的分类标准

---

## 五、对比总结 — 1 个提示词

### AI 文本总结（`ai_summary`）

**触发场景**：对比综述页面，选中文本后点击"AI 总结"按钮

**当前内容要点**：
- 将选中片段总结为一句话
- 不超过 50 个汉字
- 保留核心信息，使用学术语言

**动态占位符**：`{selected_text}` — 用户选中的文本

**可修改方向**：
- 改变输出长度（如允许 100 字、改为输出 3 个要点）
- 增加输出格式（如要求输出"核心发现 + 方法 + 局限"结构）
- 改变语言（如改为英文输出）

---

## 修改入口

所有提示词均可通过 **提示词管理页面** 在线编辑：

```
工作台 → 提示词管理 → 选择对应类型（七步精读 / 四步精读 / 长文本精读 / 文献筛选 / 对比分析）
```

优先级机制：**用户覆盖 > 系统默认 > 文件兜底 > 代码内置**

修改后即时生效，无需重启。点击"恢复默认"可还原为系统预设。
