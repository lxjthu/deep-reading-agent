# PDF 全文中文重述翻译改造计划

> 状态：待实施  
> 日期：2026-05-21

## 目标

将全文翻译中的 PDF 文献改为不分片的两步法：

1. 第一步基于全文解析文献类型并生成术语库。
2. 第二步将 PDF 提取出的全文一次性提交给 DeepSeek，要求用典雅、规范的中文完整重述全文。

提示词必须明确约束：

- 不得删减原文内容。
- 不得增加原文没有的信息。
- 不得编造事实、数据、论证、引用或结论。
- 数字、公式、表格含义、结论方向与不确定性表述必须保持一致。

## 当前实现

当前 `translation_pipeline.py` 的主流程对 PDF 和 Markdown 共用：

1. 从 Markdown 文本提取标题、摘要、引言。
2. 生成术语词典。
3. 识别章节标题层级。
4. 按标题与段落长度分片。
5. 并发逐片中文重述。
6. 合并后扫描残留英文块并补译。

`backend/routers/translation.py` 会先把 PDF 提取为 Markdown 文本，再调用同一条 `translate_md_file(...)` 管线。

## 设计边界

### PDF

PDF 改为专用全文管线：

- 保留 PDF 文本提取。
- 不再调用标题层级检测与分片重述。
- 不再对 PDF 输出做分片后的残留英文补译。
- 术语库生成改为接收全文，并在提示词中先识别文献类型，再提取后续全文重述需要统一使用的术语。
- 全文重述调用只发起一次 DeepSeek 请求。

### Markdown

本次默认保持现有 Markdown 翻译链路不变：

- 仍支持章节分片。
- 仍保留当前 YAML 注入与残留英文补译逻辑。

原因是 Markdown 输入可能已经是长文本、含 frontmatter 和复杂结构，现有分片逻辑承担了结构保留与长度控制。本次需求明确指向 PDF 不分片，先避免扩大改动面。

## 提示词改造

### 第一步：文献类型与术语库

输入 PDF 提取全文。输出应包含：

1. 文献类型判断，例如理论研究、实证研究、综述、方法论文、政策报告等。
2. 术语库 Markdown 表格。
3. 对术语使用和全文重述风格的简短约束。

提示词强调只依据输入文献判断，不得补写不存在的研究背景或方法。

### 第二步：全文中文重述

输入：

- 第一步生成的文献类型与术语库。
- PDF 提取全文。

输出：

- 只输出中文 Markdown 正文。
- 保留原文结构、标题层级、列表、表格、公式与引用痕迹中可保留的部分。
- 使用典雅、规范、清晰的中文学术表达。
- 不得摘要化、压缩化或改写成评论。
- 不得补充原文未给出的论据、例子、数据、引文或结论。

## 实施步骤

1. 在 `translation_pipeline.py` 增加 PDF 专用两步全文重述函数与提示词。
2. 调整 `backend/routers/translation.py`：
   - PDF 提取文本后走全文管线。
   - Markdown 继续走现有 `translate_md_file(...)`。
3. 保持产物类型不变：
   - `translation_md`
   - `translation_glossary`
4. 调整任务阶段进度文案，使 PDF 不再显示分片、补译等阶段。
5. 补充最小静态验证和针对函数调用边界的测试或检查。

## 风险与验证

- 全文单次请求更依赖模型上下文窗口，超长 PDF 可能超出模型可承载长度。
- PDF 提取文本质量会直接影响全文重述质量。
- 单次全文请求失败时，当前分片级别的局部重试优势会消失，需要保留整体请求重试。

验证重点：

1. PDF 翻译流程不再调用分片检测和分片重述。
2. Markdown 翻译流程行为不变。
3. PDF 仍产出中文重述文件和术语库文件。
4. 失败状态与进度状态可正确回写。
5. 提示词中存在“不增删、不编造”的明确约束。
