# AI 综述提示词说明

## 为什么有这么多提示词

AI 综述不是一次调用完成的，而是根据**精读模式**和**维度结构**的不同，走不同的写作路径。每个路径需要独立的"系统角色"和"写作指令"，因此拆成了多个提示词。

整体分为三条路线：

```
AI 综述（synthesize_dimensions / synthesize_long_dimensions）
  → 逐维度调用，每维度生成一段综述
  → 使用 system_role + dimension_prompt

七步/四步对比综述（analyze_comparison）
  → 根据维度下的子问题数量，选择单段落或多段落
  → 使用 compare_system_role + single_prompt / multi_prompt / cross_dim_prompt

长文本对比综述（analyze_long_comparison）
  → 根据是否选中多维度，选择单维度或多维度
  → 使用 compare_system_role + long_single_prompt / long_multi_prompt
```

---

## 各提示词详解

### 1. AI 综述：系统角色（`system_role`）

**用途**：设定 LLM 的身份和写作风格，用于 AI 综述（逐维度生成）。

**触发场景**：
- 「AI 综述」按钮 → 七步/四步精读的综述模式
- 「AI 综述（长文本）」按钮 → 长文本精读的综述模式

**当前内容要点**：
- 角色定位：学术文献综述专家
- 不写引言结论，直接以维度名作为小标题
- 间注法引用，转引标注格式
- 不写参考文献目录（系统自动生成）

**可修改方向**：
- 改变综述风格（如增加引言/结论、改为英文输出）
- 调整引用格式（如改为上标编号、APA 格式）
- 增加特定学科要求（如要求报告效应量、置信区间）

---

### 2. 对比综述：系统角色（`compare_system_role`）

**用途**：设定 LLM 的身份，用于七步/四步/长文本的**对比综述**功能。

**触发场景**：
- 对比综述页面点击「生成对比」→ 七步/四步模式
- 对比综述页面点击「生成对比」→ 长文本模式

**与 `system_role` 的区别**：
- `system_role` 用于 AI 综述（逐维度独立生成，最后拼接）
- `compare_system_role` 用于对比综述（一次性综合多篇文献的某个步骤/维度）

**可修改方向**：同上，但主要影响对比综述的输出风格。

---

### 3. AI 综述：逐维度写作指令（`dimension_prompt`）

**用途**：AI 综述模式下，每个维度生成综述时的写作指令模板。

**触发场景**：AI 综述逐维度循环中，每轮调用都会注入此模板。

**动态占位符**：`{dim_label}` — 当前维度名称（如"研究问题""理论框架"）

**当前内容要点**：
- 五层写作结构：梳理总结 → 源流比较 → 学术对话 → 缺漏分析 → 新起点
- 间注法引用
- 不写参考文献目录

**可修改方向**：
- 增减写作层次（如去掉"缺漏分析"，增加"方法论批判"）
- 改变分析深度要求（如要求每层至少引用 N 篇文献）
- 增加输出格式约束（如要求表格、要求按时间线排列）

---

### 4. 对比综述：单维度写作（`single_prompt`）

**用途**：七步/四步对比综述中，当某步骤**没有子问题**（或只有 1 个子问题）时，生成一段完整的综述段落。

**触发条件**：维度下的子问题数 ≤ 1

**动态占位符**：
- `{n}` — 文献数量
- `{label}` — 当前步骤/维度名称

**当前内容要点**：
- 输出恰好一段（8～15 句）
- 结构：主题句 → 各文献比较 → 共识与分歧 → 局限与方向

**可修改方向**：
- 调整句子数量范围
- 增加结构要求（如要求按时间线/方法论分组）
- 改变共识与分歧的呈现方式

---

### 5. 对比综述：多子问题写作（`multi_prompt`）

**用途**：七步/四步对比综述中，当某步骤**有多个子问题**时，按子问题分节撰写。

**触发条件**：维度下的子问题数 ≥ 2

**动态占位符**：
- `{n}` — 文献数量
- `{label}` — 步骤名称
- `{sub_count}` — 子问题数量
- `{sub_questions_list}` — 子问题列表文本

**当前内容要点**：
- 引言（1 句）+ 各子问题分节 + 结论（1 句）
- 每节标题用 `###` 格式
- 每节 1～2 段，横向比较

**可修改方向**：
- 调整分节深度（如每节增加"方法论比较"子节）
- 增加每节的最低字数/引用要求
- 改变标题格式

---

### 6. 对比综述：跨维度写作（`cross_dim_prompt`）

**用途**：七步/四步对比综述中，用户点击"跨维度综述"按钮时，一次性综合所有维度生成结构化综述。

**触发条件**：用户在对比综述页面选择跨维度模式

**动态占位符**：
- `{n}` — 文献数量
- `{step_list}` — 所有维度名称列表
- `{step_count}` — 维度数量

**当前内容要点**：
- 引言 + 按维度分节 + 跨维度结论
- 每节 1～2 段

**可修改方向**：
- 增加维度间的交叉对比（如"维度 A 的发现如何影响维度 B 的结论"）
- 增加整体性评价（如研究成熟度评估、证据强度评级）

---

### 7. 长文本对比：单维度写作（`long_single_prompt`）

**用途**：长文本对比综述中，用户选择**单个维度**进行对比时使用。

**触发条件**：长文本模式 + 只选了 1 个维度

**动态占位符**：
- `{n}` — 文献数量
- `{dimension}` — 维度名称

**当前内容要点**：与 `single_prompt` 结构类似（一段式），但措辞针对长文本精读场景。

**可修改方向**：同 `single_prompt`。

---

### 8. 长文本对比：多维度写作（`long_multi_prompt`）

**用途**：长文本对比综述中，用户选择**多个维度**（或全选）进行对比时使用。

**触发条件**：长文本模式 + 选了 2 个及以上维度

**动态占位符**：
- `{n}` — 文献数量
- `{dim_count}` — 维度数量
- `{dimensions}` — 维度名称列表

**当前内容要点**：与 `cross_dim_prompt` 结构类似（分节式），但措辞针对长文本精读场景。

**可修改方向**：同 `cross_dim_prompt`。

---

## 修改入口

所有提示词均可通过 **提示词管理页面**（PromptsTab）在线编辑，路径：

```
工作台 → 提示词管理 → AI 综述 / AI 模板生成
```

优先级机制：**用户覆盖 > 系统默认 > 文件兜底 > 代码内置**

修改后即时生效，无需重启。点击"恢复默认"可还原为系统预设。
